# Product documents (PDF drop-in folder)

Drop each client PDF into the folder shown below using the **exact file name**.
No code change is needed: a card on the Products page shows **View PDF** once its file exists
and **PDF coming soon** until then. Place files under `public/documents/...` (published at `/documents/...`).
